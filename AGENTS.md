# Repository workflow

Use FFF for file and text search within this workspace: `find_files` for names,
`grep` for contents, and `multi_grep` for OR searches. In fx, discover the `fff`
server with `capability_search` first. Prefer these to shell grep/rg/find or
built-in workspace search. Read exact known paths directly. Use scoped fallbacks
for ignored files, exact counts, unavailable FFF, or authorized external paths;
never silently widen the index to the home directory or filesystem root.

This is a colocated Jujutsu repository. Use jj for local version control. Do not
commit, activate the host, update unrelated pins, or run maintenance without an
explicit request.

`flake.nix` is generated by flake-file from declarations in `modules/inputs.nix`
and settings in `modules/den.nix`; regenerate it with `nix run .#write-flake`.
Import-tree discovers Nix modules under `modules/`; `modules/_lib/` holds
explicitly imported helpers.

Use `direnv allow` once after reviewing `.envrc`, or `nix develop --impure`.
Run `nix fmt` and `nix run .#check` for validation. Policy and command tests belong
in Nix, not standalone Python/Bash scripts. Runtime CLI glue belongs in
`writeShellApplication`; never exercise real cleanup/activation in tests.
